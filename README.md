# Tank Battle / Formation Breaker

## 실행과 검사

최종 사용자는 `dist/app.html` 파일 하나를 브라우저에서 직접 열면 됩니다. 이미지·오디오·맵 데이터·스타일·JavaScript를 모두 포함하므로 서버·Node.js·인터넷 연결이 필요하지 않습니다. 배포 HTML은 직접 수정하지 않습니다.

게시 주소는 https://nas306.github.io/ 이며 `NAS306/NAS306.github.io` 저장소의 `main` 브랜치 루트 `index.html`을 GitHub Pages로 제공합니다. 게시 시 `node build.js`로 만든 `dist/app.html`을 루트 `index.html`로 복사하고, 원본 `src/`·빌드 설정·검증 스크립트도 함께 갱신합니다. 루트 `index.html` 역시 생성물이며 직접 수정하지 않습니다. 백업(`*_BU.*`, `*_BU`), `node_modules/`, `.qa/`, `.publish/`, 중간 산출물 `dist/`는 Git 업로드에서 제외합니다. 기존 개별 배포 스크립트·외부 자산·맵은 단일 HTML에 통합되어 게시 시 별도로 필요하지 않습니다.

개발 환경은 Node.js 22 이상을 사용합니다. 최초에 `npm.cmd ci`로 고정 버전 개발 의존성을 설치합니다. `node build.js` 또는 `npm.cmd run build`로 단일 HTML을 생성하고, `npm.cmd run check`로 빌드·소스 문법·Node 회귀 검사를 실행합니다. `npm.cmd run test:browser`는 설치된 Microsoft Edge를 headless로 열어 오프라인 실행·5개 모드 진입·1라운드 즉시 시작·결과 유지·수동 복귀·모바일 배치를 검사하고 `.qa/`에 화면을 저장합니다.

원본은 `src/`에서 역할별로 관리합니다. `src/js/`의 `00`~`99` 모듈, `src/styles/`의 CSS, `src/html/body.html`을 `src/index.template.html`에 통합합니다. `build.js`의 `JS_MODULES`와 `CSS_FILES`가 명시적인 결합 순서를 정하며 새 모듈을 만들면 이 목록도 갱신해야 합니다. esbuild가 ES 모듈 의존성을 확인해 하나의 IIFE로 묶고, `src/js/99-api.js`에서 공개한 API만 `window.TankGame` 네임스페이스로 노출합니다. 자산 경로 `./assets/...`는 빌드 때 `src/assets/`의 파일을 data URL로 변환하며 맵 JSON도 번들에 포함합니다. 결과는 약 14 MB이며 CDN이나 런타임 fetch에 의존하지 않습니다.

빌드 검증 후 임시 파일을 `dist/app.html`로 교체합니다. 기존 산출물이 있으면 `dist/app_BU.html`로 백업합니다. 이전 루트의 `*_BU` 파일과 테스트 백업은 빌드에 포함하지 않습니다.

## 로그라이트 규칙

- 매 라운드 적 생성 전에 플레이어를 현재 맵의 정중앙으로 이동합니다. 남은 체력·탄약·강화는 그대로 이월하며 2라운드부터 보급 150발을 더합니다.
- 최종 결과의 `Totals`는 기존 누적 통계, `By Round`는 지표별 라운드 꺾은선 그래프입니다. 전투 통계 7종과 라운드 종료 시의 체력·잔여 포인트/탄약·무기/탱크 수치를 선택할 수 있습니다. 실패한 라운드도 포함하고 미진행 라운드는 표시하지 않습니다. 회복량에는 다음 라운드 준비 중 수리를 포함하며, 격파가 없는 라운드의 격파당 탄약과 미보유 능력은 `—`로 표시합니다. 기록은 종료 판정 직후, 연출·수리·보급 전에 한 번만 저장하며 새 실행에서 초기화합니다. 최대 10개의 메모리 내 기록만 사용하고 외부 차트 라이브러리나 저장 형식을 추가하지 않습니다.

- 시작 화면에서 `5` 또는 로그라이트 카드를 선택하면 능력·업그레이드·주사위 없이 1라운드 전투를 즉시 시작합니다. 체력 125·탄약 300·적 6대로 시작하며 플레이어 1명, 아군·본진·아이템·자동 포인트 지급은 없습니다. 업그레이드·무료 능력 선택·필수 주사위는 2~10라운드 시작 전에만 총 9회 제공합니다.
- WASD/방향키 이동, 마우스 조준, 좌클릭 사격. 로그라이트 플레이어의 무기는 일반포로 고정하며 Q 교체는 없습니다. 적과 기존 팀전의 무기 종류·교체 규칙은 유지합니다.
- 경기장의 가로·세로 크기는 뷰포트 너비입니다. 축소 없이 가로폭 전체를 채우고, 세로 방향은 플레이어를 따라 카메라가 자동 스크롤합니다. 조준은 기존과 동일하게 화면 좌표에 카메라 위치를 더해 계산합니다. 가장자리에서는 HUD 아래에 플레이어가 가려지지 않을 만큼 카메라 여유를 둡니다.
- 40초 × 10라운드. 동시 생존 적 상한은 1라운드 6대부터 매 라운드 6대씩 늘어나 10라운드 60대입니다. 보충 간격은 0.3초에서 0.06초까지 선형으로 짧아집니다. 각 라운드는 상한만큼의 적으로 시작하고, 격파로 빈자리가 생기면 이 간격으로 한 대씩 보충합니다. 생성은 빈자리와 상한을 지키며 프레임마다 최대 한 대이므로 낮은 프레임에서도 한꺼번에 몰아서 생성하지 않습니다. 라운드 길이와 격파 보상은 `src/js/42-rogue-state.js`의 `ROUND_SECONDS`, `KILL_POINTS`를 참조하며 HUD에도 같은 값을 표시합니다. 라운드별 무기 비율은 `MIXES`에 지정합니다. 작은 적 수에서 비율은 정확히 일치할 수 없으므로 누적 생성 수의 부족분을 기준으로 배분합니다.
- 주사위 강화 전 적 체력은 `90 + (라운드 - 1) × 3`, 공격력은 1라운드 피해의 `1 + (라운드 - 1) × 0.02`배입니다. 10라운드 기본 체력은 117, 공격력은 1라운드 대비 +18%입니다. 적 밀도 증가를 중심으로 난도를 올리며, 체력·공격력은 완만하게 증가합니다. `getRoundConfig`가 주사위 강화까지 포함한 생성 상한·간격·체력·공격력·이동/연사/탄속 배율을 반환하므로 실제 생성과 준비 화면 안내가 같은 수치를 사용합니다.
- 로그라이트 플레이어는 체력 125, 이동속도 200입니다. 일반포의 기본 발사 간격은 0.2초, 피해 40, 탄속 750, 비행시간 1.5초입니다. 적 체력은 90~117이므로 능력·주사위 적용 전 일반포 3발로 격파합니다. `Explosive Payload` 능력은 일반탄을 유지하면서 발사당 큰 폭발탄을 추가하고 기본 공격속도를 40%p 낮춥니다. 폭발탄은 탄속 1000, 비행시간 1.5초, 기본 반경 90, 기본 피해 15~80이며 적에게만 피해를 줍니다. 폭발 반경은 최대 150px, 사망 폭발은 최대 110px입니다. 실제 반경과 시각 효과의 최종 반경을 일치시키고, 피해는 `최소 피해 + (최대 피해 - 최소 피해) × (1 - 거리 / 반경)²`로 감소합니다. 폭발탄의 반경 절반 지점은 기본 31.25 피해입니다. 수치와 상한은 `src/js/40-rogue-balance.js`의 `ROGUE_EXPLOSION_RULES`에서 관리하며 실제 사격·스탯·능력 미리보기가 동일한 계산 함수를 사용합니다. 기존 적·팀전 대포의 수치와 선형 피해 감소는 유지합니다.

### 적 강화 주사위

결과는 이동속도·공격속도·공격력·최대 체력·탄속·Pass·Bomb의 7종이며 각 확률은 1/7입니다. Pass 외에는 강화량을 별도로 추첨하며 기본값 대비 +20~60%p의 정수 41개 값이 같은 확률로 나옵니다. Bomb는 한 번 추첨한 강화량을 적의 5개 스탯 모두에 더합니다. 예를 들어 Bomb +60%p는 5개 항목에 각각 +60%p를 누적합니다. 이후 라운드와 보충 적에도 유지하며 같은 항목 +23%p와 +37%p는 +60%p로 합산하고 곱연산으로 중첩하지 않습니다. `enemyDiceBonuses`는 횟수가 아닌 누적 백분율 포인트 정수입니다. 결과 카드에 이번 강화량과 항목별 누적 강화량을 표시하며 Pass는 기존 강화량을 유지하고 새 실행에서는 모두 0으로 초기화합니다.

카드가 완전히 등장하기 전의 클릭은 무시합니다. 등장 후에는 카드와 오버레이 배경 어느 곳을 클릭해도, 또는 Enter/Space를 눌러도 0.4초 퇴장 회전을 시작합니다. 전투와 40초 타이머는 퇴장 완료 후에만 시작하며, 연속 클릭으로 다시 굴리거나 퇴장 중 일찍 시작할 수 없습니다. 전투 시작 시 입력을 초기화해 카드를 닫은 클릭이 사격으로 이어지지 않게 합니다. 카드 타임라인은 기존 프레임 루프를 사용해 탭 비활성화 시 정지하고, 모션 감소 설정에서는 회전 대신 페이드로 표시합니다.

- 이동속도: `50 × (1 + 누적 속도 강화량 / 100)`.
- 공격속도: 기본 배율 `0.5 × (1 + 누적 공격속도 강화량 / 100)`. 발사 간격은 무기 기본 간격을 이 배율로 나눕니다.
- 공격력: 팀전 대비 배율 `0.5 × (1 + 0.02 × (라운드 - 1) + 누적 공격력 강화량 / 100)`. 대포 폭발 피해에도 적용합니다.
- 최대 체력: `90 × (1 + 누적 체력 강화량 / 100) + 3 × (라운드 - 1)`.
- 탄속: 각 적 무기 기본 탄속의 `1 + 누적 탄속 강화량 / 100`배.

종료 연출은 기존 프레임 루프에서 실제 표시 시간을 기준으로 진행하며, 탭이 숨겨지면 정지합니다. 별도 타이머나 재귀 호출을 만들지 않습니다. 결과 판정은 즉시 고정하고 연출만 분리하므로 종료 후 피해나 추가 포인트로 판정이 바뀌지 않습니다. 모션 감소 설정에서는 같은 순서와 시간을 유지하면서 슬라이드 대신 페이드로 표시합니다.

대형 탄환은 기존 공격력 배율의 하한을 적용한 뒤 탄환 피해만 절반으로 줄이므로, 중복 획득 시에도 정확히 절반이 됩니다. 사망 폭발 피해는 줄이지 않습니다. 도탄은 실제 이동 경로를 각 반사 구간으로 나눠 충돌을 검사하며 모서리 동시 접촉은 1회로 계산합니다. 반사 횟수를 모두 쓴 탄환은 다음 벽 접촉에서 소멸하고 폭발탄은 해당 위치에서 폭발합니다. 수명·관통의 명중 대상 기록은 유지하며 라운드 종료 연출 중에는 추가 피해 없이 반사만 표시합니다. 이 모드에는 내부 벽이 없으므로 외곽 경계를 벽으로 사용합니다.

### 조합과 연쇄 폭발

- `Bullet Storm + Split Barrel + Orbital Magazine`는 일반탄 13발을 발사하며 탄약 13발을 소모합니다. `Explosive Payload`를 추가하면 일반탄 13발+폭발탄 1발에 탄약 23발을 소모합니다. 일반탄 다중 사격 능력은 폭발탄 수를 늘리지 않으며 폭발탄 능력을 중복 획득하면 큰 탄환 수가 늘어납니다. `Rail Accelerator + Piercing Rounds`는 일반탄 한 발이 최대 12대를 관통합니다. 비행시간 강화는 실제 탄환 수명과 사거리에 적용됩니다.
- `Death Cascade`의 기본 최대 피해는 획득당 +40이며 누적 공격력 배율을 곱합니다. 최소 피해는 0이고 거리 비율의 제곱으로 감소합니다. 반경은 `min(110, 70 × 폭발 반경 배율)`입니다. 폭발탄 반경은 `min(150, 90 × 폭발 반경 배율)`입니다. 공격력·광역 폭약·불안정 탄두·공성 포대가 함께 적용되며 공격력 감소 효과도 폭발 피해를 줄입니다. 상한을 넘긴 반경 강화는 미리보기에서 가짜 범위 증가로 표시하지 않으며 범위 밖 적은 연쇄를 이어가지 못합니다.
- 플레이어에게 격파가 인정된 뒤 `World.onPlayerKill(tank)` 훅에서 사망 폭발을 예약합니다. `RogueWorld.handleCollisions()`가 예약 목록을 순차적으로 처리하므로 재귀 호출이나 타이머가 필요하지 않습니다. 이미 파괴된 적은 다시 맞지 않으며 폭발 한 번이 다음 적을 격파하면 새 폭발이 목록에 추가됩니다. 연쇄는 해당 업데이트의 적 수 안에서 끝납니다.
- 연쇄 폭발은 적에게만 피해를 주며 모든 연쇄 격파는 각각 포인트와 격파 회복에 반영합니다. 적의 아군 오사로 죽은 적은 플레이어 연쇄를 시작하지 않습니다. 플레이어가 이미 사망했으면 회복하지 않으며 라운드 종료 시 예약 목록을 비웁니다. 기존 적/팀전 대포의 아군·자신 피해 규칙은 유지하고 로그라이트의 추가 폭발탄과 사망 폭발은 `hitAllies: false`로 구분합니다.

## 유지보수

기존 파일 수정 전 `파일명_BU.확장자`로 백업하며 이미 있으면 덮어씁니다. 백업 파일은 실행 진입점에서 참조하지 않습니다.
모든 모드(전선전·공성 공격·공성 방어·소모전·로그라이트 및 슈퍼/관전 플레이)는 최종 승리·패배 결과를 무기한 표시하고 Mode Select 버튼을 누를 때만 모드 선택 화면으로 돌아갑니다. 종료 카운트다운과 강제 이동은 없습니다. 로그라이트의 중간 라운드 생존은 강화 화면으로 진행합니다.
모드 복귀 시 페이지를 새로 불러오지 않습니다. 앱이 등록한 복귀 콜백에서 경기의 `dispose()`를 호출하고 입력·포인터·키보드·화면 크기 이벤트와 프레임 루프, 롱프레스 및 음악 타이머를 정리합니다. 스프라이트 캐시·오디오 풀·레벨 목록은 재사용하고 준비된 모드 선택 화면을 즉시 표시합니다. 새 경기의 체력·강화·라운드 상태는 새 게임 인스턴스에서 초기화하며, 폐기된 게임의 비동기 초기화/프레임 콜백은 재시작되지 않게 막습니다.

모드 선택 화면은 5개의 이미지 카드로 구성합니다. 일반포·스캐터·대포는 실제 게임의 원·삼각형·사각형과 동일한 팀 색상·흰 테두리·체력바로 표시하고 삼각형은 실제 렌더러의 기하 함수를 재사용합니다. BASE·Stronghold도 인게임의 사각형·색상·라벨을 사용합니다. 카드 아래에 모드 이름과 설명을 두고 1~5 단축키·키보드 선택을 유지합니다. 작은 화면은 2열과 세로 스크롤을 사용하며 모션 감소 설정에서는 장식 애니메이션을 멈춥니다. 빈 배경 클릭은 전투를 시작하지 않습니다.
